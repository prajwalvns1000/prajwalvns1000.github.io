About Me

I specialize in the intersection of hardware and firmware. My studies in Electronics and Instrumentation Engineering at JSS Science and Technology University have equipped me with a deep understanding of circuit design, signal measurement, and automated systems.

How I Built This

Site Architecture

This is a purely static frontend application designed for maximum performance, security, and hosting flexibility.

User →
Custom Domain →
DNS Routing →
HTTPS (SSL) →
HTML/CSS/JS →
Static Cloud Hosting

Why Static?

The scope of a student engineering portfolio does not require dynamic databases, user logins, server-side code execution, or administrative portals. By using raw HTML5, CSS3, and vanilla ES6 JavaScript, the site achieves loading speeds under 500ms, offers no attack vectors for cross-site scripting (XSS), and can be hosted for free on CDN networks (e.g., GitHub Pages, Netlify, or Vercel).

Future Evolution

Should the profile require dynamic content editing (e.g., a blogging system or admin-managed project database), the architecture can scale to a decoupled Headless CMS:
Frontend (Static files/React) → API Layer (Serverless/Express) → Cloud Database → Admin Panel
